# 認知訓練的兩個族群

## 為什麼一套系統要分兩個版本

拉密教練系統原本的問題是：**AI 找得到最佳解，但玩家要學會的是自己找到。**
所以真正的問題不是「要不要提示」，是**什麼時候說、說到多深、什麼時候閉嘴**。

把這個問題放進認知訓練的脈絡，就出現兩個方向相反的族群：

```
兒童（8–12 歲）      認知還在建構 → 目標是「習得」
長者（65 歲以上）    認知可能在流失 → 目標是「維持」
```

它們不是「難度不同」，是**方法論相反**：

| | 兒童版 | 長者版 |
|---|---|---|
| 目標 | 習得新能力 | 維持既有功能 |
| 犯錯 | 有價值——從錯誤中學 | 有風險——可能學會錯誤 |
| 引導方向 | 100% → 40% 逐步撤除 | 依當下表現動態調整 |
| 卡關 16 回合 | 是挑戰 | 是挫折，可能就此放棄 |
| 成功經驗 | 錦上添花 | **核心需求** |

**最後一列是關鍵。** 對兒童而言，一次「自己想出來」的經驗價值最高；
對長者而言，**持續參與本身就是介入的前提**——放棄了就什麼都沒有。

## 文獻基礎

### 支持的部分

| 研究 | 發現 |
|---|---|
| Paquid 世代（法國，3,675 人追蹤 20 年） | 規律玩桌遊者失智風險低 15% |
| 2020 年嚴肅遊戲回顧 | 早期與中期失智患者在短期記憶、問題解決、反應時間、邏輯推理與溝通上有改善 |
| 台灣研究（41 位社區輕中度失智長者，12 週） | MoCA-T 顯著提升，**輕度效果量 0.522 大於中度的 0.310** |
| 現代桌遊 RCT（健康長者） | 語意流暢度改善，且遊戲組在三個月後仍維持 |

**台灣那份研究的「輕度大於中度」特別值得注意**——它跟本系統自己的模擬實驗
發現的結構一致：**介入的效果會隨著能力下降而遞減。**

### 與本設計衝突的部分

失智照護的主流方法是**無錯學習（errorless learning）**：
盡量不讓患者犯錯，因為他們有「學會錯誤」而非「從錯誤中學」的風險。
回顧研究顯示，與容錯學習（errorful learning）或不介入相比，
無錯學習在教導日常任務上更有效，而且效果能維持到追蹤期。

**而本系統的核心是刻意留出犯錯與自主提取的空間。**

| | 無錯學習 | 本系統 |
|---|---|---|
| 犯錯 | 盡量避免 | 留出空間 |
| 提示 | 立刻給完整答案 | 從輕推開始逐步加深 |
| 目標 | 建立可靠的程序記憶 | 訓練自主提取 |

**這個衝突不是設計缺陷，是適用範圍的界線。**

## 適用範圍

| 對象 | 適用 | 理由 |
|---|---|---|
| 兒童（8–12 歲） | ✓ 兒童版 | 認知在建構期，撤除引導才能訓練自主 |
| 健康中高齡預防 | ✓ 長者版 | 認知儲備的建立需要真正的認知努力 |
| 輕度認知障礙（MCI） | ✓ 長者版 | 保留部分自主提取能力，但需要成功保證 |
| **中重度失智** | **✗ 不適用** | 該族群需要完整的無錯學習，與本系統方法論相反 |

**最後一列是刻意寫出來的。** 一個宣稱「適用所有人」的認知訓練工具，
通常代表設計者沒有想清楚它在做什麼。

## 每一招訓練什麼

| 關卡 | 拉密技巧 | 認知功能 | 兒童版 | 長者版 |
|---|---|---|---|---|
| 1 | 接龍頭尾 | 視覺搜尋、序列辨識 | ✓ | ✓ |
| 2 | 補第四色 | 集合分類、屬性比對 | ✓ | ✓ |
| 3 | Joker 補缺口 | 抽象替代、心智彈性 | ✓ | ✓ |
| 4 | 破冰湊 30 分 | 計算、目標導向規劃 | ✓ | ✓ |
| 5 | 大風吹重組 | 工作記憶、執行功能 | ✓ | **✗** |
| 6 | 長龍切斷 | 抑制控制 | ✓ | **✗** |

**長者版只開前四關。** 第五、六關要求同時保持多組資訊並重排、
以及放棄現成結構換取後續機會——那是最容易造成挫折的兩種認知負荷。

> **這個對照是設計時的推論，尚未經過標準化認知評估工具驗證。**
> 要驗證需要 MoCA 或 MMSE 之類的前後測，那超出目前的範圍。

## 長者版的三個機制

### 一、動態難度

兒童版的難度由關卡決定——那是固定的課程。
長者版跟著當下的表現走，因為**認知功能會波動**：
同一個人在早上與傍晚、休息前與疲勞後，能做到的事不一樣。

```
連續卡 2 回合   → 提示深一層
連續成功 3 次   → 提示淺一層
```

**兩個門檻刻意不對稱：加強要快，撤除要慢。**
撤太快會造成挫折，而挫折的成本在這個族群高得多。

實測（O 成功、X 卡關）：

```
情境：時好時壞  X O X X O X X O

兒童版   輕 輕 輕 輕 輕 輕 輕 輕      難度不隨表現改變
長者版   輕 輕 輕 指 指 指 答 答      提示跟著表現往上爬
```

### 二、成功保證

**連續四個回合沒有成功，就直接給答案。**

不管關卡設定、不管動態難度、不管模式——這是整個系統唯一一個
「無條件覆蓋」的機制。

因為它保護的不是學習效果，是**繼續參與的意願**。
挫折累積會讓人放棄，而放棄就等於失去整個介入。

```
情境：連續卡關  X X X X X X X X

兒童版   輕 輕 輕 輕 輕 輕 輕 輕
長者版   輕 指 指  !  !  !  !  !      ← ! 是成功保證觸發
```

### 三、疲勞追蹤

認知訓練的常見做法是每次 30–45 分鐘。長者版設 30 分鐘，超過就提醒休息。

**疲勞不只是體驗問題，它會污染評估**——疲勞會讓表現看起來比實際差，
那會誤導系統的難度判斷。

## 兩個版本的完整差異

| | 兒童版 | 長者版 |
|---|---|---|
| 對象 | 8–12 歲 | 65 歲以上健康中高齡、MCI |
| 開放關卡 | 6 | 4 |
| 難度 | 固定，由關卡決定 | 動態，依表現調整 |
| 成功保證 | 不啟用 | 連續 4 回合沒成功就給答案 |
| 單次時長 | 45 分鐘 | 30 分鐘，超過提醒 |
| 允許犯錯 | 是 | 盡量避免，出錯前先確認 |
| Recap MCQ | 要通過才進關 | 只是回顧，不擋進度 |
| 措辭 | 「再看一次周圍，有東西可以動」 | 「我們一起看看這裡」 |

**Recap 那一列值得說明**：長者版不擋，因為**測驗會製造壓力，而壓力本身損害認知表現**。
同樣的題目，在兒童版是關卡，在長者版是回顧。

## 尚未做到的

**一、沒有標準化的認知評估。**
所以不能宣稱「提升了多少認知功能」。要那樣宣稱需要 MoCA 或 MMSE 的前後測，
以及對照組。

**二、沒有長者試用。**
介面的字級、對比、操作複雜度是否適合長者，目前是未知的。
而那可能比演算法更決定這個系統能不能用。

**三、沒有與臨床人員討論過分級。**
六個關卡的難度順序、以及「長者版只開前四關」這個決定，
都是根據拉密的技巧複雜度推的，不是根據認知負荷的實測。

**四、認知功能的對照是推論。**
「大風吹重組訓練工作記憶」這類對照沒有經過驗證。

**五、動態難度的參數沒有依據。**
「連續卡 2 回合加強、連續成功 3 次放鬆」這兩個數字是設計時定的。
先前對六關卡的引導門檻做過 AI 學習者模擬，發現「看起來合理」的參數
可能完全不合理——那個教訓在這裡同樣適用。

## 下一步

| 要做的 | 需要什麼 |
|---|---|
| 長者試用 | 找到願意參與的長者，最好透過社區據點 |
| 臨床討論 | 職能治療師或神經內科醫師 |
| 認知評估 | MoCA 前後測，以及對照組 |
| 介面調整 | 依試用結果 |

**前兩項可以先做，而且不需要完整的實驗設計**——
一次半小時的觀察，能發現的問題可能比一百次模擬還多。
